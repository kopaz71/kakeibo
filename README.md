# カード明細家計簿（スマホ専用）

楽天カードの明細CSVを取り込み、自動でカテゴリ分けして集計する家計簿です。
GitHub Pagesで公開し、スマホのホーム画面に追加して使います。

**明細データはスマホの中（ブラウザの保存領域）にだけ保存されます。GitHubには送られません。**
このリポジトリに置くのはプログラムだけです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 家計簿本体（画面・処理すべて） |
| `manifest.json` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | オフラインでも起動できるようにするしくみ |
| `icons/` | アイコン画像 |
| `.gitignore` | CSVやバックアップを誤ってアップロードしないための設定 |

## 1. GitHubに置いて公開する

1. GitHubにログインし、右上の「＋」→「New repository」
2. Repository name に `kakeibo` と入力し、**Public** を選んで「Create repository」
   （無料プランでGitHub Pagesを使うにはPublicが必要です。公開されるのはプログラムだけです）
3. 作成したリポジトリで「uploading an existing file」をクリックし、
   `index.html` `manifest.json` `sw.js` `README.md` と `icons` フォルダをまとめてドラッグ＆ドロップ →「Commit changes」
   - `.gitignore` はドラッグで入らないことがあります。その場合は「Add file → Create new file」で `.gitignore` という名前のファイルを作り、中身を貼り付けてください
4. 「Settings」→ 左メニュー「Pages」
5. 「Build and deployment」の Source を「Deploy from a branch」、Branch を `main` ／ `/(root)` にして「Save」
6. 1〜2分待つと、上部に `https://（ユーザー名）.github.io/kakeibo/` と表示されます

## 2. スマホのホーム画面に追加する

### iPhone（Safari）
1. Safariで上のURLを開く
2. 画面下の共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
3. 以降は**必ずホーム画面のアイコンから**開いてください
   （Safariで直接開いた場合と、ホーム画面から開いた場合ではデータが別になります。
   また、Safariで長く開かないサイトのデータは自動で消されることがありますが、ホーム画面に追加したものは対象外です）

### Android（Chrome）
1. Chromeで上のURLを開く
2. 右上の「︙」→「ホーム画面に追加」（または「アプリをインストール」）→「インストール」
3. 以降はホーム画面のアイコンから開きます

## 3. 使い方

1. ブラウザで楽天e-NAVIにログインし、「ご利用明細」からCSVをダウンロード
2. 家計簿の「取り込み」→「CSVファイルを選ぶ」でダウンロードしたCSVを選ぶ
3. 「明細」で未分類（オレンジ）のものにカテゴリを選ぶ。次回から同じお店は自動で分類されます

## 4. バックアップ（大切）

データはスマホの中にしかありません。次の場合は消えます。
- アプリ（ホーム画面のアイコン）を削除した
- ブラウザの「履歴とWebサイトデータ」を消去した
- スマホを機種変更・初期化した

月に一度、「設定」→「バックアップ」→「書き出す」を押し、
共有メニューから「"ファイル"に保存」（iPhone）やGoogleドライブなどに保存してください。
復元するときは「読み込む」でそのファイルを選びます。

## 5. プログラムを更新するとき

1. 変更を `main` ブランチに入れる。`index.html` などを変えたときは、`sw.js` の `const CACHE = "kakeibo-v21";` の数字も1つ上げる（例：`kakeibo-v22`）
2. GitHub Pages に反映されるまで数分待つ
3. スマホでアプリを開くか、別のアプリから戻ると、画面の上に「新しい版があります｜更新する」が出る。「更新する」を押すと新しい版に切り替わる
   （画面の一番上で下に引っ張って離しても、新しい版を確かめて切り替えられる）
4. 切り替わったかは、「設定」の一番下の「アプリの版：kakeibo-v◯◯」で確かめられる。PCとスマホで同じ番号なら同じ版
5. お知らせが出ないときは、10分ほど待ってから、アプリを完全に終了して（アプリの一覧で上にはじく）開き直す

更新しても、スマホに保存された明細データはそのまま残ります。
